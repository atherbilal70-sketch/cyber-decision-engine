# محرك القرارات للأمن السيبراني · Cybersecurity Decision Engine

> تم إعداده بواسطة الطالب **أثير بلال محمد** · Prepared by student **Ather Bilal Mohammed**

🌐 ثنائي اللغة: العربية / English — بزر تبديل أعلى الصفحة.

تطبيق ويب تفاعلي باللغة العربية لدعم قرارات الأمن السيبراني ومواءمتها مع الأعمال، مبني على منهجية كتاب
**Rational Cybersecurity for Business** للمؤلف Dan Blum (Apress 2020, CC BY 4.0).

## التبويبات
1. **معايرة المؤسسة والحوكمة** — الحجم، القطاع، النضج، شهية المخاطر، نموذج الحوكمة، الامتثال، وتحليل باريتو للأولويات الست.
2. **السيناريو والفرز ARM** — ملف مخاطر الأصل، مصفوفة نافذة المعالجة CHML، التقييم الثنائي BRA، وتحليل PESTLE.
3. **حاسبة Open FAIR ودفتر الأستاذ** — محاكاة مونت كارلو، منحنى تجاوز الخسارة، ALE الكامن والمتبقي، وROSI.
4. **المعالجة والضوابط و RACI** — القبول/التخفيف/النقل/التجنب، ضوابط NIST CSF مع ربطها بـ ISO 27001 وNIST 800-53 وCOBIT 5 وCSA CCM، مذكرة قبول الخطر، ومصفوفة RACI.
5. **السياسات والثقافة وخطة 90 يوماً** — هرم السياسات، رسالة التوعية الإيجابية، مقاييس الثقافة الستة، موجز مجلس الإدارة، وورقة خطة النجاح.

## الذكاء الاصطناعي
- يعمل التطبيق كاملاً بالمحرك المحلي دون أي اتصال خارجي.
- لتفعيل التحليل الذكي: اضغط ⚙️ **الذكاء الاصطناعي** وأدخل مفتاح Claude API الخاص بك.
- المفتاح يبقى في متصفحك ويُرسل مباشرة إلى Anthropic فقط. يُنصح بتحديد سقف إنفاق من لوحة Anthropic.
